# Workout Routine

All working sets use a target of **1–2 reps in reserve (RIR)**.

## Weekly schedule

| Day | Workout |
| --- | --- |
| Monday | Upper A |
| Tuesday | Lower + Aesthetic |
| Wednesday | Rest |
| Thursday | Upper B |
| Friday | Aesthetic |
| Saturday | Rest |
| Sunday | Rest |

## Monday — Upper A

1. High-Incline Machine Press — 3 sets × 6–10 reps
   - Alternatives: Incline Dumbbell Press; Smith Incline Press
2. Neutral-Grip Pulldown — 3 × 6–10
   - Alternatives: Lat Pulldown; Pull-Up
3. Cable Lateral Raise — 3 × 10–20
   - Alternatives: Machine Lateral Raise; Dumbbell Lateral Raise
4. Braced Cable Row — 2 × 8–12
   - Alternatives: Chest-Supported Row; Machine Row; Seated Cable Row
5. Cable arm superset — 2 rounds each
   - Overhead Tricep Extension — 2 × 8–15
     - Alternative: Cable Pushdown
   - Cable Curl — 2 × 8–15

## Tuesday — Lower + Aesthetic

1. Leg Press — 3 sets × 6–10 reps
2. Leg Curl — 3 × 8–12
3. Leg Extension — 2 × 10–15
4. Standing Calf Raise — 3 × 8–15
5. Cable Lateral Raise — 3 × 10–20
   - Alternatives: Machine Lateral Raise; Dumbbell Lateral Raise
6. Neck superset — 2 rounds each
   - Neck Iso Front — 2 × 10–20
   - Neck Iso Back — 2 × 10–20

## Thursday — Upper B

1. Lat Pulldown — 3 sets × 8–12 reps
2. Pec Deck — 2 × 10–15
3. Reverse Pec Deck — 3 × 10–20
4. Preacher Curl — 2 × 8–15
5. Braced Cable Row — 2 × 8–12
   - Alternatives: Chest-Supported Row; Machine Row; Seated Cable Row
6. Overhead Tricep Extension — 2 × 8–15
   - Alternative: Cable Pushdown
7. Incline Dumbbell Press — 3 × 6–10

## Friday — Aesthetic

1. Reverse Pec Deck — 3 sets × 10–20 reps
2. Cable equipment block
   - Cable Lateral Raise — 3 × 10–20
     - Alternatives: Machine Lateral Raise; Dumbbell Lateral Raise
   - Cable Fly — 2 × 10–15
   - Straight-Arm Pulldown — 2 × 10–15
   - Cable Tricep Pushdown — 2 × 8–15
3. Dumbbell equipment block
   - Hammer Curl — 2 × 8–15
   - Dumbbell Shrug — 3 × 8–15
   - Dumbbell Wrist Extension — 2 × 12–20
